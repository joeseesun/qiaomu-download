# Security and privacy

- 只接受 HTTPS，不接受 URL 用户名/密码、自定义端口、localhost 或私有 IP。
- 单视频模式固定使用 `--no-playlist`，防止一个链接意外扩张为整套内容。
- 固定使用 `--no-overwrites`，保护已有文件。
- Cookie 先不读取，公开抽取失败后才回退到本机浏览器；不复制、存储或打印 Cookie。
- 不把 Cookie、令牌或凭证放入命令参数之外的日志和结果。
- 不绕过 DRM、付费墙、地区限制或其他访问控制。
- Spotify 只读取公开页面元数据，不读取 Premium 离线缓存、客户端数据库、Cookie 或令牌，不解密 Spotify 音频。
- Spotify 音频来自经评分的公开 YouTube 页面；结果必须披露音频来源 URL 和匹配置信度。自动模式只处理一个 track URL。
- 微信视频号由本包内置适配器处理；禁止自动化微信客户端、点击、播放或刷新微信内嵌页面。
- 视频号在线解析只有在用户明确同意发送本次公开分享 URL 后才启用；不得上传 Cookie、微信登录态、抓包或设备信息。
- 视频号本地后端只从锁定的官方 Release 下载并校验 SHA-256；证书信任和系统代理修改分别授权并在任务结束时恢复代理快照。
- 小红书、抖音、TikTok、Instagram、Facebook、微博等容易出现登录验证或风控的平台，下载前必须提醒用户：本技能只做 URL/yt-dlp 解析，不操作客户端或网页 UI；验证码、登录确认和安全验证由用户手动完成。
- 上述平台禁止使用 Computer Use、Accessibility、AppleScript 或其他 UI 自动化点击、刷新、登录、输入验证码或处理风控页面。
- 公开解析失败后最多执行一次本机浏览器 Cookie 回退；仍失败就停止，不做高频重试。
- 更新来源只信任 yt-dlp 官方 GitHub release；使用现有安装管理器完成升级。
- 只清理本次任务新创建、名称含当前媒体 ID 的格式分片。
