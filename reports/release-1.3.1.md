# 1.3.1 — 视频号下载链路修复

根据 coolbat-vibe 在 issue #7 提供的现场报告和补丁修复：媒体下载显式直连并使用浏览器 User-Agent；解密前探测后端能力，必要时使用本机已安装的锁定后端。回退不扫描任意历史二进制，要求安装记录与包内锁定版本及归档 SHA-256 匹配。

本次验证：34 项单元/传输测试、24 项触发检查和包结构校验通过。真实 loopback HTTP 传输在模拟系统代理不可达时完整接收媒体夹具，并检查 UA；覆盖配置后端优先、有效锁定安装回退、篡改安装记录拒绝、无解密能力时不下载、签名参数和不完整传输保护。已安装 v260714 的真实 `decrypt --help` 能力探测通过；v260907 官方 cmd 源码无 decrypt 子命令。

未操作微信、代理或证书；未重新验证真实微信 CDN、报告人的视频链接、完整加密视频下载或其他平台实机。浏览器 UA 是针对报告场景的兼容措施，不承诺消除所有 CDN 中断。
